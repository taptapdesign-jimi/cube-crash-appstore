# iOS Stack to Six

One local ChatGPT Work project for Native iOS development and visual design.

## Project settings

- Name: **iOS Stack to Six**
- Primary local folder: `/Users/user/cube-crash`
- Project instructions: paste the entire contents of [PROJECT_INSTRUCTIONS.md](PROJECT_INSTRUCTIONS.md).
- Visual library: [SKILL.md](SKILL.md), [STYLE_GUIDE.md](STYLE_GUIDE.md), [REFERENCE_INDEX.md](REFERENCE_INDEX.md).

Edit the existing Stack to Six project if you want to keep its chats together, or create a new local project with the name above. Through the project menu, use Edit project → Add folder to attach the primary folder. If it is already attached, keep it. No second folder attachment is needed for game design because it is inside the primary folder. Use Make primary if needed. Preserve any existing project instructions you still need when merging the supplied instructions.

The attached repository's AGENTS.md already routes visual tasks to the local art skill. The supplied project instructions reinforce this routing; no account-wide custom instructions are necessary for this project. A typed local path or Markdown link alone does not grant filesystem access. Local sources are not automatically available in a cloud-only chat or on another device.
