# Game Design project

For visual design, character/scene/image generation and artwork review, read
`SKILL.md` and `STYLE_GUIDE.md` in this directory. Use `REFERENCE_INDEX.md` to
open the relevant actual PNG images before creating artwork. Human-and-dog
identity, ordinary/Wild/Special dice, effects, Home heroes and Journey worlds
have separate reference sections. Keep the library and original game art intact.
Save candidates in `output/<task-name>/`. Do not integrate art into the runtime
or perform app builds/installations as a side effect of a design task.
`PROJECT_INSTRUCTIONS.md` contains ready-to-paste ChatGPT project instructions.
