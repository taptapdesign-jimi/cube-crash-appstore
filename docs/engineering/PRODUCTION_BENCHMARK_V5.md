## Complete change record

This benchmark captures the complete working tree explicitly promoted by the
user after the 2026-09-19 Journey, audio, card-motion and Clean Board work.
Git is the authoritative file inventory; the sections below record the intended
behavior and the limits of the available evidence.

### Journey return and frame stability

- Journey-family Clean Board returns preserve the prepared Hub/World tree and
  no longer wait on already-settled final gameplay FX before navigation starts.
- World return preparation is measured separately, reveal-frame boundaries are
  marked, and bulk idle retirement filters protected owners before one batched
  GSAP traversal.
- The accepted Journey modal automatic enter, committed vertical dismiss and
  Play/Continue return flights run at 1.4x speed while direct horizontal drag,
  flip snap, recoil and the post-game return reminder retain their own timing.
- Artwork/front-face pinch uses a dedicated scale owner capped at 1.20x and
  cleans pointer ownership without stealing flip or dismiss gestures.

### Audio foreground recovery

- WebKit soundtrack resume is bounded to one second. A context that remains
  suspended returns to the established gesture retry; a context whose audio
  clock resumed despite a pending native promise continues without restarting.
- Pending resume work is cancelled on pause, replacement, disposal, background
  ownership changes and Music OFF. Generation checks reject late completion
  from retired transports.
- Diagnostic markers distinguish foreground resume state from SFX ownership.
  The accepted physical retest retained one running soundtrack voice, while the
  original missing-music incident remains preserved as historical evidence.

### Gameplay replacement motion

- Restored or reset locked placeholders with a stale `_spawned` marker rejoin
  the authored staggered Merge 6 replacement bounce instead of being unlocked
  together at scale 1.
- Both defensive regular and Juice recovery routes use the same replacement
  motion and a 100ms separation. Spawn counts, selected values, cells, scoring,
  sound and gameplay decisions remain unchanged.

### Clean Board celebration boundary

- Exit, Continue and Play Again synchronously remove the shared celebration
  canvas before the first asynchronous boundary or exit animation.
- Area 55 confetti, Forest leaves and Beach bubbles all lose live particles,
  scheduled waves and the shared RAF in the CTA click frame. Navigation abort
  uses the same complete lifecycle cleanup.
- Existing modal, card and board exit choreography continues immediately after
  cleanup; particle lifetime can no longer delay or visually trail the action.
